# 01. AI Skill 基础概念

## 1. 定义回顾

**Skill = 在分布变化下仍能稳定完成某类任务的能力**。

四个属性：

1. **可观察**：行为或输出口径可以观测。
2. **可泛化**：在新样本上不退化。
3. **可拆解**：能脱离其他技能被独立测试。
4. **可度量**：有可比指标。

## 3. Skill 的五层栈

| 层 | 内容 | 谁负责 |
| --- | --- | --- |
| L0 | 硬件 / 推理引擎 | 平台方 |
| L1 | 基座模型 | 模型方 |
| L2 | 对齐 / 指令微调 | 模型方 |
| L3 | 工具 / 检索 / 记忆 | 应用方 |
| L4 | 业务提示与编排 | 应用方 |

每一层都可能成倍放大或削弱上层 Skill。

## 4. 横向通用 Skill 与纵向专业 Skill

- **横向通用 (horizontal)**：跨任务的能力，如"读懂"、"规划"。
- **纵向专业 (vertical)**：领域专精，如"读心电图"。

实战常组合：通用基模型 + 横向提示 + 纵向 RAG + 纵向工具。
