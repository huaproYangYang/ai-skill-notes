# 02. AI Skill 分类法

## 1. 维度组合

任何一项具体技能都可以落在以下四个维度的交叉点上：

| 维度 | 取值 |
| --- | --- |
| 模态 | text / vision / audio / 3D / 多模态 |
| 任务类型 | 生成 / 理解 / 推理 / 决策 / 工具 |
| 认知层级 | 记忆 → 创造 (Bloom 6 层) |
| 领域 | 编程 / 数学 / 法律 / 医疗 …… |

## 2. 常见组合

- `text × 生成 × 应用 × 写作`
- `vision × 理解 × 分析 × 文档解析`
- `text × 推理 × 应用 × 数学`
- `multi × 工具 × 决策 × 个人助理`

## 3. Skill 簇 (Skill Cluster)

相互依赖的技能会形成"簇"。例：

> **编程簇**：阅读 → 生成 → 重构 → 调试 → 测试 → Review。

脱离簇谈"我会写代码"是没有意义的。Skill 是网络，不是单点。
